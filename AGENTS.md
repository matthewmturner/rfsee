# Source references

Always include an adjacent link to the authoritative source when implementing logic that is not
specific to this application and is defined by an external standard, specification, protocol, or
published algorithm.

Prefer primary sources and link to the exact section that explains the implementation. Put the
link in a code comment or documentation comment where a future reader will encounter it while
reading the relevant logic.

Examples include date and time formats, wire protocols, file formats, encoding rules, scoring
formulas, and calendar or numerical algorithms.
